How to compile a C/C++ code
```
g++ -o hello hello.c
```

A few source code files can potentially be manages and compiled by hand. But at some point you are going to need some **automation**.

## Make 

### Overview
- One of the earliest (and still most popular) automation tools for building software is called 'Make'
- **Make** uses a configuration file (called **Makefile**) to define what .c files are needed and which dependencies exist between them.
**NOTE** : we use **tabs not spaces**  if it has **tab** , it is **a shell command**

E.g 
```
all:hellow
hellow:
	echo "Hello, World!"
	g++ main.cpp -o main
clean:
	rm -f main
```

```
default:
	g++ main.cpp -o main
```

run `make` in the command line
We can run like
`make all` : which execute the command in all
`make hellow` : which compiles `hellow`
`make clean` : which deletes executable

### Makefile Complexity
- As a project increases in size so can its Makefile
- Add in cross-platform options and flags and the complexity increases even more
- So we need to automate the creation of Makefiles so that Make can automate the compiling of the source code -> which is why the release of **CMake** (the C stands for **cross-platform**)

## CMake
CMake uses a configuration file called CMakeLists.txt
a. Define your project in CMakeLists.txt
b. Run CMake to create the Makefile
c. Build your project using Make
d. Add code, fix things , you go back to c
e. If you add new .c files or alter the dependencies then jump to step a.

### Out-of-source builds
Traditionally Makefile are placed in the same dir as the source code but CMake generates Makefiles in a different directory
The CMakeLists.txt file is in the source dir, but the automatically generated build files are separate, so as not to overwhelm your source directory

### Cross build platform
**CMake** can generate build files for other build systems not just **Make**, but also **Ninja, Visual Studio and XCode**. This means the same CMakeLists.txt can be used to generate the files for alternative build systems.

## Ninja

Ninja is yet another build system which is fast, which is meant to replace Make. It is designed to have its input files generated by a higher-level build systems like CMake.
