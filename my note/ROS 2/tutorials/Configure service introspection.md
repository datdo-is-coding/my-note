#introspect
**Goal** : configure service introspection for a service client and a server.
**Tutorial level** : Advanced
By default, you cannot observe or monitor when a service gets called, nor what the request or response was.
We need to **configure the service**

In this demo, we will learn how to configure service introspection state for a service client and a server and monitor service communication with `ros2 service echo`
