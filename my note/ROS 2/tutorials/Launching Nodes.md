#nodes #startup

Automate launching nodes by using launch file. Launch files allow you to **start up and configuer a number of executable containing ROS 2 node simultaneously** 

## TASKS
Running a launch file
`ros2 launch turtlesim multisim.launch.py`

Learn more about how to setup launch files: https://docs.ros.org/en/jazzy/Tutorials/Intermediate/Launch/Launch-Main.html
